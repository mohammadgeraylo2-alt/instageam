# سایت شخصی تلگرام (بدون فیلترشکن)

یه کلاینت وب شخصیِ تلگرام با تم مشابه تلگرام، ساخته‌شده با FastAPI + Telethon.
**فقط برای حساب شخصی خودت طراحی شده** — تک‌کاربره، نه یه سرویس عمومی.

## قبل از هر چیز: گرفتن api_id و api_hash

1. برو به https://my.telegram.org (اگه فیلتره، یه‌بار از نت موبایل/DNS متفاوت/پروکسی موقت استفاده کن — فقط همین یه مرحله لازمه)
2. با شماره‌ات لاگین کن → **API development tools**
3. یه اپ جدید بساز (اسم و توضیح دلخواه) → `api_id` و `api_hash` بهت داده می‌شه

### اگه my.telegram.org در دسترست نیست
لازم نیست `TG_API_ID`/`TG_API_HASH` رو دستی ست کنی. اگه این دوتا env var خالی باشن،
پروژه با کتابخونه‌ی `opentele2` یه API رسمی اپ اندروید تلگرام تولید می‌کنه و خودکار
استفاده می‌کنه. تو این حالت برای ورود، به‌جای مرحله‌ی شماره+کد، رو لینک «به‌جاش با
session string وارد شو» تو صفحه‌ی لاگین بزن و session string خودت رو (مثلاً از
`local_login.py` یا یه ربات دیگه که خودت داری) پیست کن.

**نکته:** session string معادل کامل دسترسی به حسابته — دقیقاً مثل فایل session، هرگز
جایی share‌ش نکن و تو کد کامیت نکن.

## اجرای محلی (تست)

```bash
pip install -r requirements.txt
export TG_API_ID=1234567
export TG_API_HASH=abcdef1234567890abcdef1234567890
uvicorn main:app --reload
```

بعد برو `http://localhost:8000` و با شماره‌ی خودت لاگین کن.

## دیپلوی روی Railway

1. این پوشه رو به یه **ریپوی GitHub خصوصی** (Private) پوش کن — نه عمومی، چون فایل سشن حاوی دسترسی کامل حسابته
2. تو Railway → New Project → Deploy from GitHub repo
3. تو تنظیمات پروژه → **Variables** این‌ها رو اضافه کن:
   - `TG_API_ID`
   - `TG_API_HASH`
4. دیپلوی کن. بعد از اولین لاگین موفق، یه فایل `tg_session.session` روی سرور ساخته می‌شه که سشن رو نگه می‌داره.

### نکته‌ی مهم درباره‌ی ماندگاری سشن
فضای فایل Railway معمولاً بین **ری‌استارت‌ها** می‌مونه ولی با هر **ری‌دیپلوی** (پوش کد جدید) ممکنه پاک بشه، یعنی باید دوباره لاگین کنی. اگه می‌خوای همیشه ماندگار بمونه، از Railway Volume برای مسیر پروژه استفاده کن (تو تنظیمات سرویس → Volumes).

## نکات امنیتی (حتماً بخون)

- **هرگز فایل `tg_session.session` رو کامیت نکن** — همین الان به `.gitignore` اضافه شده. این فایل معادل دسترسی کامل به حساب تلگرامته.
- ریپو رو **Private** نگه دار. اگه public باشه و کسی api_hash یا فایل سشن رو ببینه، به حسابت دسترسی پیدا می‌کنه.
- این سایت **فقط برای خودت** طراحی شده. اگه لینکش رو به کس دیگه بدی و اون هم لاگین کنه، سشن حسابش جایگزین سشن فعلی می‌شه (چون سرور تک‌کاربره‌ست) — یعنی برای چند نفر کار نمی‌کنه و اصلاً نباید به این شکل به کس دیگه داده بشه.
- اگه گوشیت رو گم کردی یا حس کردی سرور به خطر افتاده، از تنظیمات تلگرام (Settings → Devices) می‌تونی سشن این وب‌کلاینت رو ریووک کنی.

## امکانات فعلی
- لاگین با شماره + کد + رمز دومرحله‌ای (در صورت نیاز)، یا با session string آماده
- لیست چت‌ها با آخرین پیام و تعداد نخونده‌ها
- باز کردن یک چت، دیدن پیام‌ها (متن + عکس + ویدیو)، ارسال پیام متنی
- ریپلای، فوروارد، ادیت و حذف پیام (نگه‌داشتن روی پیام یا راست‌کلیک برای منو)
- به‌روزرسانی خودکار پیام‌های چت باز (هر ۳ ثانیه)

## امکانات پیشنهادی بعدی (اگه خواستی اضافه کنم)
- فیلدرها (Unread/Bots/...)، پین و میوت کردن چت
- استیکر/GIF/پیام صوتی
- سرچ داخل چت‌ها
- نوتیفیکیشن مرورگر برای پیام جدید
