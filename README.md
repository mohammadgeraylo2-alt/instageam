# اینستا بدون فیلتر — با لاگین واقعی

نسخه‌ی جدید: با یوزرنیم/پسورد واقعی اینستاگرام لاگین می‌کنی و فید خانه + اکسپلور + پروفایل رو
از سرور خودت (بدون فیلتر) می‌بینی.

## ⚠️ ریسک‌های مهم (حتماً بخون)
- این پروژه از `instagrapi` استفاده می‌کنه که یه کتابخونه‌ی **غیررسمیه** و API خصوصی اینستاگرام رو شبیه‌سازی می‌کنه — خلاف قوانین اینستاگرامه.
- لاگین از IP سرور (مثلاً Railway) ممکنه توسط اینستاگرام مشکوک تشخیص داده بشه → **چک‌پوینت** یا حتی **بلاک موقت اکانت**.
- ممکنه بعد از لاگین کد تایید دومرحله‌ای (2FA) یا "challenge" بخواد — کد challenge (تاییدیه) رو باید از اپ رسمی/ایمیل بگیری، اینجا فقط 2FA رو می‌شه وارد کرد.
- سشن‌ها (لاگین‌ها) فقط **توی حافظه‌ی سرور** نگه داشته می‌شن؛ با هر ری‌استارت Railway، همه باید دوباره لاگین کنن.
- پسورد فقط لحظه‌ی لاگین استفاده و **هیچ‌جا ذخیره نمی‌شه**.

## اجرای لوکال
```
pip install -r requirements.txt
uvicorn main:app --reload
```
برو به `http://localhost:8000`

## دیپلوی روی Railway
1. پوشه رو به یه ریپوی گیت‌هاب جدید وصل کن (مثل قبل).
2. Railway خودش تشخیص می‌ده پایتونیه (به‌خاطر `requirements.txt`) و طبق `Procfile` اجراش می‌کنه — نیازی به تنظیم دستی نیست.
3. از **Settings → Networking → Generate Domain** آدرس HTTPS بگیر.

## مینی‌اپ تلگرام
دقیقاً طبق راهنمای قبلی: تو `@BotFather` برو `Bot Settings → Menu Button` و آدرس Railway رو بذار.

## محدودیت‌های فعلی
- ویدیو/ریلز اضافه شد؛ تب ریلز پایین صفحه، ویدیوها اتومات پلی می‌شن وقتی تو دیدن.
- endpoint ریلز (`clips/home/`) رسمی نیست — ممکنه اینستاگرام فرمتش رو عوض کنه؛ در این صورت به‌صورت خودکار fallback می‌کنه رو اکسپلور و ویدیوهاشو فیلتر می‌کنه.
- استوری و دایرکت (پیام‌رسانی) هنوز پیاده‌سازی نشده.
- اگه اینستاگرام «challenge» خواست، باید دستی از طریق اپ رسمی حلش کنی و دوباره امتحان کنی.

## گام بعدی پیشنهادی
اگه ویدیو/ریلز درست کار کرد و خواستی استوری هم اضافه بشه، بگو ادامه بدم.
